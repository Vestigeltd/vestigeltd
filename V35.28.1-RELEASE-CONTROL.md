# V35.28.1 — Owner Lock Visibility Correction

## Scope
This release preserves the V35.27.9 checkout presentation and the existing Owner tab and payment-admin key. It adds anonymous restock-demand polling, expands the Owner Console's business intelligence, and hardens owner/indexing and BC10000 canonical behaviour. It does not add stock-depletion forecasting.

## Corrections
- Corrects the preview-discovered locked-state defect where the shared `.btn` display rule made **Lock Console** visible before authentication.
- Adds a targeted hidden-state safeguard and advances Owner Console asset cache keys to V35.28.1.
- Expanded the sold-out state into a 13-flavour BC10000 checkbox poll that accepts multiple selections.
- Collects aggregate flavour selections only; no poll name, e-mail, mobile, account, raw IP address or user agent is stored.
- Uses a browser-local submitted flag as a low-friction duplicate deterrent; results remain directional because voters are not identity-verified.
- Adds owner-only poll responses, total votes, leading flavour and ranked demand.
- Adds Today, 7-day and 30-day funnel views covering visitors, page views, shop views, product selections, baskets, checkout starts, payment notices and confirmations.
- Adds revenue, units sold, average order value, conversion and abandonment indicators without speculative stock forecasting.
- Keeps all intelligence inside the existing locked Owner Console.
- Adds response-header noindex protection for `/owner` while retaining the existing navigation link.
- Canonicalises `/bc10000` and `/bc10000/index.html` to `/bc10000/` and updates the sitemap modification date.
- Adds V35.28.1 regression safeguards.
